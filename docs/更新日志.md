# 更新日志

维护者：singerTang

## 1.1.0（2026-09-17）

源码发布版本为 1.1.0，对应 Git 标签 v1.1.0。服务器部署单独执行，本文不代表服务器已经更新。

### 新增与改进

- 左侧栏底部新增共享回收站，支持搜索、分页、跨页勾选、单个及批量恢复、彻底删除；清空采用 5 秒倒计时后手动确认，无需输入文字，取消后重新打开重新计时。
- 回收站入口位于统计栏上方；内容使用图库同款卡片，支持整卡点击、键盘勾选与选中高亮。删除及恢复操作使用统一站内确认弹窗，区分可恢复与不可恢复的后果。
- 回收站默认列表，可切换卡片；复用图库数字分页及每页 30、50、100、200、500 条选项。回收站独立记住视图与条数偏好，默认每页 100 条；缩略图预览不改变勾选。
- 回收站工具栏限制搜索宽度，集中排列期限设置与操作；空回收站隐藏批量按钮，区分全库为空与搜索无匹配。
- 默认保留 30 天，可设置 7、30、60、90 天；修改仅影响之后移入回收站的图标，启动时及每小时清理到期项。
- 恢复保留上传时间；原分类或文件夹不存在时回退为未分类或无文件夹归属。清理失败保留记录重试，共享图片不会误删。

- 分类支持多选筛选及未分类条件，文件夹采用树形选择控件。
- 统一选择控件，支持搜索、键盘操作和选中状态展示。
- 批量上传可统一指定分类和文件夹，新增及上传表单支持快捷创建分类。
- 分类管理放大弹窗；图标选择分为已选择与未选择，已选择默认收起。
- 默认每页 100 条，增加 200、500 条档位；排序仅提供“最近上传”和“名称升序”，默认“最近上传”采用同名归组规则，移除界面的旧上传排序及最近修改。
- 同名归组按筛选结果中每组最新上传时间排序，组内按上传时间倒序；完整名称一致才归为一组，分页前完成排序。
- 调整卡片操作区、预览角标、名称与分类间距。
- 侧栏显示软件版本，新增只读版本接口，版本号统一取自 package.json。

### 修复

- 补充可逐项移除的筛选摘要及统一清除入口，清除条件保留排序、每页条数和累计勾选。
- 筛选结果显示匹配数量，区分图库为空与条件无匹配；查询失败隐藏旧列表并提供重试。

- 主列表选择跨页、搜索及筛选保留；当前页全选与全部清空语义分离。
- 批量操作覆盖全部已选项，成功后只移除已处理项，失败保留选择。
- 分类管理全选未选择图标需确认，保存后才更新归属。
- 忽略过期列表请求，避免较早的搜索结果覆盖新查询。

### 升级影响

- 无新增依赖。旧库启动时自动追加回收站字段、到期索引和设置表，原记录默认保持正常状态。
- 需要更新后端、前端及两个包清单文件，并重启服务，详见版本发布指南。
- 不覆盖数据库、上传文件及环境配置。
- 普通 JSON 导出只包含正常图库，不包含回收站；完整备份仍需实际数据库及 uploads。旧版代码不识别回收站状态，不能直接覆盖回退。
