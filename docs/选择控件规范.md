# 图标管理软件：选择控件规范

本文件是[全局界面规范](全局界面规范.md)的选择交互专项补充。颜色、文字层级、按钮及弹窗规则以全局规范为准；下列业务边界继续保留。

## 参考依据

- [Eagle](https://en.eagle.cool/)：参考素材管理中将文件夹、分类整理和筛选组织在一起的方式，不复制它的多标签业务模型。
- [Ant Design Select](https://ant.design/components/select)：参考统一单选、多选、搜索、选中状态和弹层位置处理。
- [Ant Design TreeSelect](https://ant.design/components/tree-select)：参考层级展开、父子缩进和搜索选择。

本项目使用原生 JavaScript 实现共用控件，没有安装上述产品或组件库。

## 控件选择

| 场景 | 控件 | 行为 |
|---|---|---|
| 类型、排序、每页条数 | 单选 | 点击选项后立即生效并关闭。 |
| 顶部分类筛选 | 可搜索多选 | 点击复选项后立即筛选，面板保持打开；支持未分类和清空全部选择。 |
| 迁移、新增、批量上传中的文件夹 | 可搜索层级单选 | 箭头展开或收起子级；点击名称选中该级；搜索完整路径以区分同名文件夹。 |
| 新增、编辑、批量上传中的分类 | 可搜索单选 | 一次只选择一个分类，允许未分类；快捷新建后自动选中。 |

## 视觉与交互约定

- 触发器统一为 36px 高、6px 圆角、浅灰边框，右侧使用相同下拉箭头。
- 展开与键盘聚焦显示蓝色边框；选项选中显示浅蓝背景与勾选标记。
- 多分类在触发器内显示已选数量，完整名称可以悬停查看；清空后显示全部分类。
- 弹层选项区域最大高度为 280px，超出后内部滚动；搜索框和清空区域固定可见。
- 弹层空间不足时向上展开，并限制在视口内；同一时间只打开一个选择面板。
- 点击外部或按 Esc 关闭。方向键移动选项，回车选择，Tab 离开选择面板。
- 文件夹初次展开显示各级，可手动收起；选中后的触发器显示完整路径。
- 未分类与不归属任何文件夹含义不同，不能混用。

## 业务边界

- 多选分类是筛选条件之间的“或”关系，图标本身仍只属于一个分类。
- 选择迁移目标不会筛选图标，也不会立即移动图标；必须勾选图标并点击迁移。
- 新增和批量上传中的选择只更新表单，提交或开始上传后才保存。
- 主列表勾选在本次页面会话内跨翻页、搜索、分类、类型、文件夹和排序保留；刷新页面不保留。
- 主列表显示累计已选数量和当前页已选数量；全选或取消全选只作用于当前页，“清空已选”清除所有累计选择。
- 批量下载、迁移和删除使用全部已选图标。失败保留选择，下载完成保留选择，迁移或删除成功后只移除此次处理的选择。
- 分类管理的图标选择与主列表独立。搜索不清空勾选，全选前确认本次新增数量、原已选数量和合计数量；取消确认不改变勾选，保存后才写入分类。

## 实现与验证

- 共用逻辑：`public/selection-controls.js`。
- 共用样式：`public/style.css` 中的 `choice-` 类与 `--choice-` 变量。
- 原有隐藏的 `select` 保留值和表单语义，界面操作通过 `change` 事件交给原业务逻辑。
- 程序直接设置表单值后调用 `refreshSelectionControls()` 同步显示。
- 浏览器回归：`node --test test/selection-controls.test.js test/selection-state.test.js`，覆盖选择控件、跨筛选勾选及分类全选确认。Windows 使用已安装的 Edge；其他系统需要已有的 Playwright Chromium。
- 更新部署时，需要同时上传 `public/index.html`、`public/app.js`、`public/style.css` 和新增的 `public/selection-controls.js`。
