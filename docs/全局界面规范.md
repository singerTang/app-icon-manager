# 图标管理软件：全局界面规范

维护者：singerTang

状态：规范已建立，现有页面尚未全部按此规范统一。本文是后续界面修改的基线，不表示全站改造已完成。

## 1. 适用范围与原则

覆盖图库、回收站、文件夹、分类管理、新增编辑、批量上传、图标预览及确认弹窗。

- 沿用现有蓝色主色、浅灰页面、白色内容区和中文字体，不引入组件库或新主题。
- 同一类组件只有一套基础规则；尺寸差异必须对应明确用途，不能按页面临时发挥。
- 颜色表示操作或状态，不用于随意装饰；标题保持深色，不随风险等级变成红色。
- 共用颜色、字号、间距、圆角写入 CSS 变量。业务页面负责排列，不重新定义组件基础外观。
- 不通过视觉调整改变已确认的分类归属、选择范围、删除期限或分页语义。
- 选择控件和勾选规则详见《选择控件规范》，该文档是本规范的专项补充。

## 2. 颜色与底色

以下基线沿用现有颜色；警告色属于待补充的语义变量。

| 用途 | 颜色 | 使用位置 |
|---|---|---|
| 页面背景 | #F7F8FB | 主内容工作区 |
| 内容表面 | #FFFFFF | 侧栏、工具栏、卡片、弹窗 |
| 次级表面 | #F1F5F9 | 普通说明、表头、图标预览背景 |
| 普通边框 | #E2E8F0 | 分隔线、容器边框 |
| 控件边框 | #CBD5E1 | 输入框、次按钮、下拉框 |
| 主要文字 | #0F172A | 标题、名称、正文 |
| 次要文字 | #64748B | 标签、帮助、时间、数量说明 |
| 弱化文字 | #94A3B8 | 占位和禁用；不承载关键后果说明 |
| 主操作 | #2563EB | 保存、开始上传、恢复、可恢复操作的确认 |
| 主操作悬停 | #1D4ED8 | 蓝色实心按钮悬停 |
| 选中背景 | #EFF4FF | 选中行、卡片、选项 |
| 危险操作 | #DC2626 | 永久删除确认按钮、错误与不可恢复提示 |
| 危险背景 | #FEF2F2 | 不可恢复后果说明 |
| 成功 | #059669 / #ECFDF5 | 成功图标及轻提示，不用于普通保存按钮 |
| 警告，待补充 | #B45309 / #FFFBEB | 存在限制或需要注意的后果，但尚未发生错误 |

文字被鼠标选中时的系统高亮不是提示框的底色，不作为组件配色依据。状态不能只靠颜色区分，还要有明确文字。

## 3. 标题与文字层级

| 层级 | 字号／行高／字重 | 用途 |
|---|---|---|
| 页面及品牌标题 | 18 / 26 / 600 | 应用名称、回收站等页面标题 |
| 弹窗及分区标题 | 16 / 24 / 600 | 新增图标、分类管理、移入回收站 |
| 正文及主要控件 | 14 / 22 / 400 | 确认问题、表单内容、主按钮 |
| 辅助说明 | 13 / 20 / 400 | 操作后果、字段帮助、表格次要字段 |
| 紧凑元信息 | 12 / 18 / 400 | 类型角标、时间、数量补充 |

- 沿用现有中文字体栈，不按模块换字体。
- 弹窗正文固定左对齐；标题不加感叹号、不写长段落。
- 标题使用动作加对象，例如“移入回收站”“彻底删除图标”，不用笼统的“提示”。
- 中文文案使用中文标点；名称使用「名称」，数量和结果直接写明。
- 长名称在列表中省略并保留完整提示；确认弹窗中换行显示，不省略待操作对象。

## 4. 尺寸、间距与容器

| 项目 | 标准 |
|---|---|
| 间距刻度 | 4、8、12、16、24、32px |
| 页面水平内边距 | 24px；窄屏 16px |
| 同组控件间距 | 8px；不同操作组 16px |
| 标准控件 | 高 36px、圆角 6px |
| 紧凑行内按钮 | 高 32px、圆角 6px，限卡片、列表和分页 |
| 图标按钮 | 标准 36×36px；紧凑区 32×32px |
| 卡片 | 圆角 10px、内边距 12px、轻阴影 |
| 弹窗 | 圆角 16px、统一阴影、统一遮罩 |
| 搜索框 | 常规宽 320–360px，不随宽屏无限拉长；窄屏允许换行 |
| 弹窗遮罩 | rgba(17, 24, 39, 0.45)，模糊 2px |

表头和内容使用同一列定义。工具栏按功能分组，不用大段空白把一个操作组拆到页面两端。弹窗内容超高时内部滚动，标题与底部操作保持可见。

## 5. 按钮规范

| 类型 | 外观 | 适用动作 |
|---|---|---|
| 主按钮 | 蓝底白字 | 新增、保存、上传、恢复；移入回收站的最终确认 |
| 次按钮 | 白底、浅灰边框、深色文字 | 取消、返回、全选、清空已选、下载 |
| 文字按钮 | 无底无框，灰色或蓝色文字 | 返回图库、快捷新增分类等辅助入口 |
| 危险入口 | 白底红字，悬停浅红 | 工具栏和行内的删除、清空入口 |
| 危险确认 | 红底白字 | 彻底删除、清空回收站、删除分类或文件夹的最终确认 |

- 每个独立操作区最多一个实心主操作；不能把同区所有按钮都染成蓝色。
- 按钮文字写明动作，例如“移入回收站”“保存分类”，避免只有“确定”而无法判断后果。
- 危险入口允许红字提醒，可恢复的“移入回收站”确认仍使用蓝色；红色实心确认表示不可直接撤销。
- 所有按钮共享禁用规则：灰底、灰字、无阴影、不可点击；不在回收站或单个弹窗内单独设置透明度。
- 焦点使用统一可见描边，不等同于选中背景。加载时按钮显示动作进度并禁止重复提交。
- 圆角和高度由按钮尺寸类别决定，不由所在页面决定。

## 6. 弹窗规范

基础结构为标题区、正文区、操作区；关闭按钮统一使用现有描边 SVG，不混用字符 × 与 SVG。

| 区域 | 规则 |
|---|---|
| 标题区 | 标题 16px，左右内边距 24px，上下 16px；右侧关闭按钮 |
| 正文区 | 左右 24px，上下 20px；主要问题 14px，后果说明 13px |
| 后果说明 | 与问题间隔 12px；内边距 12px；普通说明浅灰，危险说明浅红 |
| 操作区 | 左右 24px，上下 16px；右对齐，取消在左、执行在右，间距 8px |
| 宽度档位 | 简单输入 400px；操作确认 460px；常规表单 520px；分类管理等复杂操作最大 1200px |
| 小屏边界 | 距视口左右至少 16px，高度不超过 90vh |

- 同一类弹窗共用外壳与确认函数，不新增浏览器原生 confirm 或 prompt。
- 有后果的确认默认聚焦“取消”；Tab 在弹窗内循环，Esc 关闭并取消，不触发提交。
- 确认弹窗不通过点击遮罩直接执行操作。关闭后焦点回到触发入口。
- 清空回收站保留用户确认的 5 秒倒计时；取消后重新打开重新计时，计时结束只解锁按钮，不自动执行。
- 倒计时只用于清空回收站，不自动扩展到其他删除或保存操作。

## 7. 确认提示内容模板

每个提示只回答三个问题：操作什么、影响哪些对象、能否恢复。不展示没有意义的“其中 0 个不在当前页”。

| 场景 | 标题 | 主要问题 | 后果说明 | 执行按钮 |
|---|---|---|---|---|
| 单个移入 | 移入回收站 | 将「名称」移入回收站？ | 图标将从图库中移除，可在回收站恢复。超过保留期限后自动清理。 | 蓝色“移入回收站” |
| 批量移入 | 移入回收站 | 将已选的 N 个图标移入回收站？ | 同上；只有跨页数量大于 0 时补充“其中 M 个不在当前页，也会一并移入。” | 蓝色“移入回收站” |
| 恢复 | 恢复图标 | 将「名称」／所选 N 个图标恢复到图库？ | 保留原上传时间与归属；原分类或文件夹不存在时调整归属并提示。 | 蓝色“恢复到图库” |
| 永久删除 | 彻底删除图标 | 彻底删除「名称」／所选 N 个图标？ | 图片文件将被清理，此操作无法撤销，删除后不能再从回收站恢复。 | 红色“彻底删除” |
| 清空 | 清空回收站 | 彻底删除回收站中的全部 N 个图标？ | 包括搜索结果之外及其他页面的图标，清空后无法恢复。 | 红色“清空回收站（5 秒）”，结束后去掉计时 |
| 删除文件夹 | 删除文件夹 | 删除文件夹「名称」？ | 图标保留并取消文件夹归属；有子文件夹时不能删除。 | 红色“删除文件夹” |
| 删除分类 | 删除分类 | 删除分类「名称」？ | 不删除图片；有正常图库图标使用时不能删除。 | 红色“删除分类” |
| 分类全选 | 全选未选择图标 | 勾选当前搜索范围内的 N 个图标？ | 已选 M 个，确认后共 K 个；保存后才更新归属。 | 蓝色“勾选 N 个” |

不可恢复提示是警示区，不能与普通帮助文字同样弱化。分类全选保留既有确认要求，但应迁移到站内统一弹窗。

## 8. 提示与空状态

| 类型 | 表现 | 生命周期 |
|---|---|---|
| 普通帮助 | 13px 灰字，必要时浅灰底 | 紧邻对应控件，持续展示 |
| 注意事项 | 浅黄底、深黄色文字及明确说明 | 问题或限制存在期间展示 |
| 危险说明 | 浅红底、红色文字 | 不可恢复确认内持续展示 |
| 字段错误 | 控件红边，字段下方红字 | 修正后消失，不能只弹短提示 |
| 操作成功 | 共用轻提示，图标加“已恢复 N 个”等短句 | 约 2.5 秒自动关闭 |
| 操作失败 | 明确失败原因、保留用户输入；涉及列表时提供重试 | 不能只依赖一闪而过的轻提示 |
| 真正为空 | 图标、简短标题、一句说明 | 不展示无意义的禁用批量按钮 |
| 筛选无匹配 | “没有找到匹配的图标”，提供清除条件入口 | 不误导用户重新上传 |
| 加载失败 | 持续失败提示及重试入口 | 不把旧结果显示为新条件的结果 |

## 9. 选择、分页和布局

- 单选、多选、层级选择统一使用现有 choice 控件，不新增一套下拉视觉。
- 主图库与回收站共享页码渲染和分页样式，状态互相独立。
- 列表与卡片的选择使用相同蓝色边框／选中底色，勾选区域至少 32px；行内操作和预览不触发勾选。
- 鼠标悬停、键盘聚焦、已选中应能区分；不能只加蓝色边框却看不出复选框状态。
- 工具栏区分筛选和批量操作；有批量选择时明确累计数量和当前页数量。
- 默认每页 100 条，可选 30、50、100、200、500；回收站默认列表，单独记住视图和条数。
- 搜索和分页偏好遵守已确认业务逻辑；页面刷新是否清除选择不由样式改造改变。

## 10. 当前待统一清单

以下是本次代码核对发现的现状，不是已经修复的结果。

| 优先级 | 现状 | 统一方式 |
|---|---|---|
| 第一批 | .btn 使用 8px 圆角，choice 使用 6px；按钮高度受不同 padding 影响 | 建立标准 36px、紧凑 32px 的统一尺寸变量 |
| 第一批 | 回收站、普通次按钮、确认按钮各自定义禁用透明度或颜色 | 共用一套禁用态，不用页面选择器补丁 |
| 第一批 | .modal 与 .action-dialog 的遮罩、正文留白分别维护 | 共用弹窗颜色、间距与遮罩变量 |
| 第一批 | 关闭按钮有 SVG 和字符 × 两套形态 | 统一关闭图标和命中区域 |
| 第一批 | 分类管理全选仍调用原生 confirm | 接入 confirmAction，保留原有选择范围与确认行为 |
| 第二批 | 帮助文字分布于 category-help、trash-help、action-detail 等局部规则 | 保留布局类，外观改由共用文字／提示语义控制 |
| 第二批 | 全局控件、表单、分页存在不同字号、边距组合 | 按用途归入规范尺寸，不按页面重写 |
| 第二批 | 页面水平留白存在 16、22、24、28px 等组合 | 内容级统一 24px，嵌套组件使用内部间距 |

实施顺序：先共用样式变量与基础组件，再迁移调用方，最后逐页检查。避免仅在样式文件末尾不断叠加覆盖规则；不在本轮顺便重构业务代码。

## 11. 验收清单

- 图库、回收站、新增编辑、分类管理和上传界面的同类组件尺寸一致。
- 同屏只有必要的实心主操作，普通说明、警告、危险提示有清楚区别。
- 确认弹窗标题、正文、提示区和操作区符合统一字号与留白。
- 禁用、悬停、焦点、加载和选中状态齐全，键盘操作可用。
- 长名称、无数据、搜索无匹配、失败、部分成功均有对应文案。
- 桌面常用宽度 1366、1440、1920px 下搜索不无限拉长，弹窗不溢出；窄屏弹窗保持视口边距。
- 多选、分类单归属、跨页累计勾选、删除恢复及 5 秒清空规则无回归。
- 改动后运行对应浏览器专项并实际查看截图，不能仅凭 CSS 或静态检查声称界面完成统一。
